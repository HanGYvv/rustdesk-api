# RustDesk API Docker Image S6

Self-hosted RustDesk API container image with s6-overlay.

## Images

- `rustdesk-api-s6`: the s6-overlay-based image repository.
- `rustdesk-api-s6:vX.Y.Z`: immutable release tags.
- `rustdesk-api-s6:latest`: the latest release.

## Overview

This repository provides the s6-based Docker image for deploying the RustDesk
API service.
It includes the API service and the related configuration needed for a
self-hosted deployment.

For full installation and runtime details, see the project documentation in the
main repository README.
